Berliz

Berliz connects clients with trainers and gyms. It handles bookings, payments, training programs and progress tracking in one place. It is live in production with real users, and its first paying client came in November 2026.

Spring Boot and PostgreSQL on the back end, an Angular web client, JWT authentication, WebSockets for real-time features, and Stripe for payments. A React Native mobile client is in development.
